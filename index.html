Push–Pull Attentional Anchoring for Diffusion Concept Erasure

N. Chatthee, Tagon Sompong, Ekapol Chuangsuwanich, Supasorn Suwajanakorn

Introduces a bounded push–pull objective in cross-attention space that achieves a state-of-the-art erasure–preservation trade-off by suppressing target concepts while limiting collateral damage to related concepts. For example, the method effectively erases “Barack Obama” while preserving “Will Smith.” It additionally provides controllable erasure strength and generalizes across architectures, including SD 1.4 and FLUX.

Zero-guidance Segmentation Using Zero Segment Labels

Pitchaporn Rewatbowornwong*, N. Chatthee*, Ekapol Chuangsuwanich, Supasorn Suwajanakorn

Introduces zero-guidance segmentation for discovering and labeling semantic image regions without prompts, annotations, or fine-tuning. The method uses attention masking to balance local and global contextual information.

Diffusion Autoencoders: Toward a Meaningful and Decodable Representation

Konpat Preechakul, N. Chatthee, Suttisak Wizadwongsa, Supasorn Suwajanakorn

Introduces a diffusion autoencoder that factorizes an image into a semantic code produced by a learnable encoder and a stochastic code modeled by a conditional diffusion model. This representation enables near-exact reconstruction, linear semantic manipulation, and downstream representation learning.
